# net/http 플랫폼 v0.1.1

이 버전은 내장 Swagger UI의 HTML, CSS, JavaScript가 올바른 `Content-Type`으로 전달되도록 수정합니다. 애플리케이션 설정을 바꿀 필요는 없습니다.

문자열 응답에 `Content-Type`을 지정하면 플랫폼이 그 값을 유지합니다. 값이 비어 있으면 기존 기본값인 `text/plain; charset=UTF-8`을 사용합니다.

Preview 후보 `v0.1.1-preview.1`의 코어 의존성은 `v0.7.0-preview.4`입니다. 발행 결과는 [릴리스 운영](../../RELEASING.md)의 절차에 따라 확인할 수 있습니다.
