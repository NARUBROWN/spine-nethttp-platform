# net/http 플랫폼 v0.1.0 시작

`github.com/NARUBROWN/spine-nethttp-platform`은 HTTP 계약 `spine.http-adapter/v3`를 구현합니다. 이 소스의 Preview 조합은 `v0.1.0-preview.2`와 코어 `v0.7.0-preview.4`입니다. 태그의 공개 설치 성공은 release manifest로 확인합니다. CLI `v0.4.3-preview.4`는 net/http 생성과 업데이트를 지원합니다. HTTP v2 코어에는 연결할 수 없습니다.

`spine.New(nethttp.Option())` 또는 `nethttp.New()`로 앱을 구성합니다. 코어는 DTO 바인딩과 multipart 파싱을 담당하며 플랫폼은 원시 입출력, 본문 읽기 제한과 서버 수명을 담당합니다.

`boot.HTTPOptions.TLS`에 인증서를 담은 `*tls.Config`를 지정하면 HTTPS로 실행합니다. 공개 실행 진입점은 `Serve` 하나이며 `WithTLS` 선택 인자로 준비 기본값을 교체할 수 있습니다. 외부 서버에 handler만 연결한 경우 TLS 설정은 외부 서버 소유입니다.

기존 Echo의 native 경로와 middleware는 자동 변환하지 않습니다. 표준 `http.Handler` middleware를 `WithMiddleware`에 전달하며 먼저 전달한 middleware가 바깥에 배치됩니다. net/http 자체의 패닉 복구를 끌 수 없으므로 `DisableRecover: true`는 준비 오류입니다.

사용 예시는 [README](../../README.md), 발행과 승격은 [릴리스 운영](../../RELEASING.md)을 참고하세요. CLI 생성, 공개 설치 조합과 HTTP/2 정책은 별도 작업입니다.
