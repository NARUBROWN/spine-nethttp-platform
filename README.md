# Spine net/http 플랫폼

이 저장소는 `v0.1.0`의 Preview, RC, 정식 릴리스 구조를 준비한 초기 기준입니다. HTTP v3와 TLS 제품 구현은 preview 대상 PR에서 검토합니다. 아직 제품 태그와 GitHub Release를 발행하지 않았습니다.

기본 브랜치는 preview이며 rc와 main으로 차례로 승격합니다. 코어 후보는 `v0.7.0-preview.3`, 플랫폼 후보는 `v0.1.0-preview.1`입니다. 고정한 코어 소스로 CI를 검사하고 공개 설치는 실제 코어 태그 발행 후 확인합니다.

채널, 승인 환경과 발행 순서는 [릴리스 운영](RELEASING.md)을 참고하세요.
